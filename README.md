# cis695-public

Public, sanitized appendix materials for a CIS 695 project centered on running a youth IoT / smart-home themed camp.  
This repo is meant to share *process + artifacts* (planning docs, setup notes, worksheets, marketing drafts) without including private course or instructor-identifying details.

## What’s in this repo

Most of the content lives in [`/docs`](docs):

- **Home Assistant / platform notes:**  
  - [`docs/home-assistant-setup-notes.md`](docs/home-assistant-setup-notes.md)
- **Network design / topology:**  
  - [`docs/network-topology.md`](docs/network-topology.md)
- **Planning + admin artifacts:**  
  - [`docs/cost-summary.md`](docs/cost-summary.md)  
  - [`docs/time-log.md`](docs/time-log.md)
- **Camp activities / student-facing materials:**  
  - [`docs/team-building-activity.md`](docs/team-building-activity.md)  
  - [`docs/student-showcase-worksheet.md`](docs/student-showcase-worksheet.md)
- **Marketing materials:**  
  - [`docs/marketing/`](docs/marketing/) (flyer + social copy)
    - [`docs/marketing/README.md`](docs/marketing/README.md)

You may also see an [`/assets`](assets) folder for images/figures used by the docs.

## Privacy / sanitization note

This is a *public* repo. Names of instructors/participants and any sensitive or identifying details are intentionally omitted or generalized.  
If you spot something that shouldn’t be public, please open an issue or contact the repo owner.

## Scope / non-goals

- This repo is **not** a polished “turnkey curriculum.”
- Hardware, network environments, and Home Assistant add-ons differ—treat these documents as **reference notes and examples**, not guaranteed step-by-step instructions.

## Contributing / feedback

Issues and small improvements are welcome:
- Typos, broken links, clarity improvements
- Safer defaults / security notes
- Alternate hardware suggestions

If you submit changes, please avoid adding any private course identifiers or personal data.
