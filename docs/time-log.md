### April 23, 2026
- Added Room 6 instructor demo network to the topology (VLAN 16 / VLAN 26) following the existing room numbering pattern
- Began configuring VLANs and SSIDs on the UniFi Express 7
- **Issue encountered:** Hit the UniFi Express 7 per-band SSID limit of 4 SSIDs per radio — the original per-room SSID design (13 SSIDs total) exceeded this hardware constraint
- Researched resolution options: SSID consolidation, additional APs with AP Groups, and 802.1X RADIUS dynamic VLAN
- **Resolution selected:** UniFi Private Pre-Shared Keys (PPSK) — allows a single SSID to assign devices to different VLANs based on which passphrase they connect with, without requiring a RADIUS server
- PPSK reduces the design to 3 total SSIDs (`IoT-Lab-Instructor`, `IoT-Lab-Trusted`, `IoT-Lab-IoT`) while preserving per-room VLAN isolation
- Each room's Raspberry Pi and IoT devices will use their own room-specific passphrase to land on the correct VLAN automatically
- Pushed documentation updates to GitHub
- Estimated time: 1.5 hours
